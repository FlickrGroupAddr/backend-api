# Orientation

**RFC 2119 keywords. MUST and MUST NOT are absolute. SHOULD is a strong default a good argument may
overrule. MAY is optional.**

**For a session that lost its context, or a person who has been away.** Read down. **Stop as soon as
you can answer the question you arrived with.**

**This file is a router, not a summary.** It holds almost no facts of its own on purpose — a second
copy of a decision is a second thing to keep in step, and the copies drift silently. Every row below
points somewhere authoritative.

## Read in this order

| # | Read | Why, and when to stop |
|---|---|---|
| 1 | `CLAUDE.md` | Loads automatically. The rules that bite, and the four naming rules |
| 2 | `docs/architecture/DECISIONS.md`, **ADR-01 first** | Numbers run most-important-first. **Stop reading when you have enough** — the file says so itself |
| 3 | `~/.claude/projects/*/memory/MEMORY.md` | One line per memory. Open only the ones your task touches |
| 4 | **The one file you are about to change** | Not its neighbors |

**That is the whole path.** Four steps, and step 4 is usually a single module.

## What NOT to read, and why

**Do NOT read all of `src/` preemptively.** A full catch-up on 2026-08-15 read every source file and
**the source was worth maybe a fifth of the value at by far the largest cost.** Read a module when
you are about to touch it.

| Skip | Because |
|---|---|
| `docs/TRACEABILITY.md` | **Generated.** `scripts/traceability.py` writes it |
| `docs/architecture/*.drawio` | **Generated.** `scripts/build-diagram.py` writes it, and a hand edit is lost. Changing it? Read `docs/architecture/DIAGRAM-NOTES.md` first, and **render the result and look at it** |
| `docs/lrc-spike/` | Archived evidence. Read it if the Lightroom client is your task, otherwise skip |
| `worker-configuration.d.ts` | Generated by `wrangler types`, and larger than all hand-written code |
| `vendor/` — **the archive only** | 8.35 MB of Adobe's. **`vendor/README.md` is NOT skippable**: it holds the SDK's location and the `luac` invocation |

## Five traps, each of which has already cost real time

**ADR-01 outranks everything.** Where an outcome could mean a person declined, it is terminal.
**Widening the retryable set in `src/adds/classify.ts` is the most dangerous edit in this
repository.**

**Local D1 is two different files.** `wrangler d1 execute --local` and a running `wrangler dev` can
open different SQLite files, and the CLI reports `no such table` rather than admitting it. See
`docs/SETUP.md`.

**`X:` is an SMB share on a NAS.** It breaks git ownership, Node file watching, and Lightroom
catalogs. Anything holding a live lock or a database belongs on local disk.

**The diagram and the traceability matrix are generated.** Edit the generator, never the artifact.

**A filesystem search that finds nothing may mean the filter was wrong.** On 2026-08-15 a session searched `C:\` for `luac`, declared it absent, and wrote that into two files — while `vendor/README.md` documented it. **Grep this repository's docs before searching disks.**

**Recall about installed APIs has been wrong repeatedly.** Read `node_modules/<pkg>` for package
shape, probe the real runtime for runtime capability, and scan the CLI binary for harness behavior.

## Where the state actually lives

**Nothing here restates status. These are the files that hold it.**

| Question | File |
|---|---|
| What is live in production? | `README.md`, the status table |
| What was decided, and why? | `docs/architecture/DECISIONS.md` |
| What is decided but NOT built? | That file's **"Still open"** section |
| What was rejected, and why? | That file's **"Considered and rejected"** table |
| What does Flickr really do? | `docs/FLICKR.md` — several rows contradict Flickr's own docs |
| How do I run it? | `docs/SETUP.md` |
| Where did the Lightroom client get to? | `docs/LRC-CLIENT-NOTES.md` |
| What is planned for the crypto? | `docs/architecture/KEY-ROTATION-NOTES.md` |
| Where is the Lightroom SDK, and how do I parse-check Lua? | **`vendor/README.md`** |
| Is a tool installed, and where? | **The docs above, BEFORE searching disks.** A filesystem search answers "does a file match my pattern", and a wrong pattern returns clean |

**Two files carry decisions that are DECIDED AND UNBUILT**, and both say so at the top:
`KEY-ROTATION-NOTES.md` and `LRC-CLIENT-NOTES.md`. **Neither is an ADR yet, deliberately** — an ADR
must be verified by a test or declare inspection, and claiming inspection for behavior nobody wrote
is the forced link `scripts/traceability.py` exists to prevent.

## Prove you are caught up

```
npm run check
```

**Quote the number the runner prints, never one read from a document** — including from this
file. That count has been wrong FOUR times, most recently on 2026-08-15.

```
python scripts/mutation-check.py
```

**Run it before and after any change to `test/`.** A green suite proves it AGREES with the code,
never that it would NOTICE the code being wrong.

## If your context was compacted

**`claude --continue` does not discard anything. Compaction does**, when a conversation outgrows the
window, and it happens whether or not anyone restarts.

**The full transcript survives at `~/.claude/projects/<slug>/<session-id>.jsonl`**, one JSON object
per line. The harness's own message says to read it for specifics. **That is usually cheaper than
re-reading this codebase.**

**Then follow the four steps above rather than reading everything.** The repository is the durable
memory; the conversation never was.
